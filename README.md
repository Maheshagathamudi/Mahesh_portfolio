# Agathamudi Mahesh | AWS DevOps & Software Engineer Portfolio

Welcome to my personal portfolio repository! This is a modern, premium, and highly interactive developer portfolio built with **Astro**, **TypeScript**, and **Vanilla CSS**. It features high-performance rendering, a dark/light theme switcher, customizable canvas-grade background effects, and interactive project slide animations.

🔗 **Live Link:** [mahesh-portfolio.vercel.app](https://Mahesh_portfolio.vercel.app) *(or your deployed Vercel URL)*

---

## 🚀 Key Features

* **⚡ Lightning Fast Performance**: Built with Astro 5.0 for near-zero client-side JavaScript overhead.
* **🌓 Dual Theme System**: Dark mode (deep purple/lilac) and light mode (soft violet/gray) with theme memory.
* **📱 Responsive Grid & Flex Layout**: Optimised for all screen sizes, adapting from widescreen 4K monitors to phones.
* **📈 Interactive Projects Showcase**: Desktop horizontal scroll animations that gracefully transition to mobile grid layouts.
* **✉️ Styled Contact Form**: Responsive user feedback and contact form connected with your socials.

## 💻 Local Development

Get this project running locally on your computer in just a few steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18.17.1+ or v20+ recommended).

### Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Maheshagathamudi/Mahesh_portfolio.git
   cd Mahesh_portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:4321/` to preview the site.

4. **Build for Production:**
   To compile and compress the website into static files ready for deployment:
   ```bash
   npm run build
   ```
   The production-ready files will be generated inside the `/dist` directory.

## 🚀 Deploying to Vercel

This project is pre-configured for instant deployment on Vercel:

1. Import your GitHub repository into your Vercel Dashboard.
2. Vercel will automatically detect **Astro** as the framework.
3. Keep the default settings:
   * **Build Command:** `npm run build`
   * **Output Directory:** `dist`
4. Click **Deploy**!
